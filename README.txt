# Heavy Equipment Website

Website statis sederhana untuk perusahaan sparepart dan rental alat berat.

## Struktur
- index.html
- css/style.css
- js/script.js
- assets/

## Menjalankan di XAMPP
1. Extract folder `heavy-equipment-website` ke `C:\xampp\htdocs\`
2. Pastikan Apache XAMPP berjalan.
3. Buka:
   http://localhost/heavy-equipment-website/

## Mengganti nomor WhatsApp
Buka `js/script.js` dan ubah:
const WHATSAPP_NUMBER = "6281294529897";

Gunakan format nomor internasional tanpa tanda +.

## Catatan
Data unit, sparepart, email, alamat, dan nomor WhatsApp adalah contoh dan perlu diganti dengan data perusahaan.
Gambar saat ini menggunakan URL gambar eksternal agar folder tetap ringan.
